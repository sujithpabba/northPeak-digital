# Optimization Changelog

## Overview

The website was optimized to improve performance, accessibility, SEO, and overall user experience using Lighthouse recommendations.

---

## 1. Improved Color Contrast

### Change
Updated button, badge, footer, and text colors to meet WCAG contrast requirements.

### Benefit
- Improved readability.
- Increased Accessibility score.
- Better user experience for visually impaired users.

---

## 2. Added Accessible Labels

### Change
Added `aria-label` attributes to:

- Social media icons
- Mobile navigation button

### Benefit
Improved screen reader compatibility and navigation.

---

## 3. Improved Mobile Navigation

### Change
Added:

- `aria-expanded`
- `aria-controls`
- Navigation landmark identifiers

### Benefit
Improved accessibility for assistive technologies.

---

## 4. Improved Semantic HTML

### Change

Added:

- `<main>` landmark
- Correct heading hierarchy

### Benefit

Improved page semantics and accessibility.

---

## 5. Added SEO Metadata

### Change

Added:

- descriptive page title
- meta description
- robots.txt

### Benefit

Improved search engine optimization.

---

## 6. Added Footer Attribution

### Change

Added the required footer credit:

Built for Digital Heroes Training Task

linked to:

https://digitalheroesco.com

### Benefit

Satisfied the live build requirement.
